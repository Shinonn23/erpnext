# Custody UI condition matrix

Status: **checks written; all browser results unrun**. Case names refer to `erpnext/loan/doctype/custody_loan/ui_test_custody_loan.js`. Requirements are tested through DOM interactions; read-only generated-link query handlers are additionally inspected after the real UI installed them. Inspecting a handler is not proof that every excluded candidate was exercised in a dropdown.

Scope is loan-related controls and the dependent document fields used by these flows. Generic selling tax/discount/pricing conditions and unrelated ERPNext modules are outside this suite. Effective site conditions, including native/custom layout overrides, are captured separately by `custody_loan_ui_preflight.inventory`; UAT has no coverage until its read-only inventory is supplied.
