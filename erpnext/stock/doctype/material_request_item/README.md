Items requested in the parent Material Request.

Rate and Amount are the company-currency estimate and its quantity total. price_list_rate stores the catalog baseline used when the request was prepared. The company policy app controls which users may read or edit prices.

The six estimate_supplier / estimate_currency / estimate_rate / estimate_exchange_rate / estimate_source / estimate_price_date fields remain in the schema for historical requests only. They are hidden, read-only and not copied into new requests; new requests use the standard Rate and locked Estimated Buying Price List.
